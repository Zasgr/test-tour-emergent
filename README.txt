Новый проект

Для просмотра:
1. Распакуйте архив
2. Откройте index.html в браузере

Структура файлов:
- index.html - главная страница
- data.js - данные тура
- index.js - логика приложения
- style.css - стили
- vendor/ - библиотека Marzipano
- tiles/ - тайлы панорам (многоуровневые)
- img/ - изображения хотспотов

Этот тур использует тайловую систему для оптимальной
загрузки на всех устройствах, включая мобильные.

Создано с помощью VR Tour Studio.
